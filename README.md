# Dr. Nezah Balal — Research Portfolio

Research projects in computational electromagnetics and applied physics: compact particle
accelerators & inverse free-electron lasers (IFEL), applied magnetism & permanent-magnet
undulators, antenna design, and millimeter-wave / micro-Doppler radar — modeled in COMSOL
Multiphysics and MATLAB.

Live site: https://nezahb-max.github.io/ · ORCID: https://orcid.org/0000-0003-4382-4053

Static HTML site (no build step). Pages: `index.html`, `accelerators.html`, `magnetics.html`,
`antennas.html`, `radar.html`.

## Analytics

Cloudflare Web Analytics remains enabled. Optional Google Analytics 4 uses the separate
personal-site property `562275457`, web stream `16270803825`, measurement ID
`G-135T32RDCL` (a public tag ID, not a secret). Reporting time zone: Israel.

Every HTML page loads `assets/analytics.js` and `assets/analytics.css`. The Google
script loads only on the production HTTPS hostname after the visitor accepts analytics.
Consent preferences expire after 180 days and can be changed through the footer.
Privacy explanations are available in English and Hebrew.

Enhanced measurement handles page views, engagement, 90% scrolls, supported YouTube
events and common download links, including PDFs. Custom events add `contact_click`
(email/phone method only), `file_download` for MPH links and `outbound_click`
(destination hostname only). Do not treat clicks as completed downloads or sent emails.
Page addresses omit query strings and fragments; referrers are reduced to origins.
Automatic outbound-click, site-search and form measurement are disabled in this stream.

For a controlled production test, append `?analytics_test=1` to an HTML page and
accept analytics. This enables GA4 DebugView. The developer filter
`Mark development tests` is in **Testing** state: it labels matching events and does
not discard them. Do not describe test or owner visits as automatically excluded.
Cloudflare's existing counter is independent and also records production QA visits.
To avoid GA4 measurement during ordinary owner browsing, decline it in this browser.
Local previews never load Google's tag, even if consent is granted.
